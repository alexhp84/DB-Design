# DB Design: Slice and Dice

Database design exercise taking a schema through normalization, with SQL scripts for each stage.

## Contents
- `sliceanddice.sql`: base schema
- `Second Normal Form 2NF.sql`: schema normalized to 2NF
- `Third Normal Form 3NF.sql`: schema normalized to 3NF
- `Slice And Dice Design.png`: entity design diagram

## Skills
Relational modeling, normalization (1NF to 3NF), SQL
